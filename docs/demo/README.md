# 演示报告（Mock 数据）

`overview.html` 是**用 `runner_mode=mock` 生成的演示报告**，用于展示报告的版面与交互：

- 双曲线图（Prefill / Decode），**鼠标在图上滑动**可看到十字准线与数值浮层
- 可展开 / 收起的参数说明
- 结果汇总表：10 列，表头可点击排序
- 硬件信息区块与 llama.cpp 启动参数留档
- 单文件、内联 CSS/JS/SVG，**零 CDN 依赖**，可直接离线打开

> ⚠️ **重要**：报告里的 tps / 耗时**全部是合成数据**，不是任何真实硬件的性能结果。
> 真实的吞吐、显存占用与 OOM 判定必须在 Windows 11 + Strix Halo 目标机上实测。

自行查看：直接用浏览器打开 `overview.html`。
